Install Userscript

Install Tampermonkey in your browser. The userscript endpoint requires bearer auth, so a plain link click cannot trigger an install — download with curl and open the saved file, which Tampermonkey will then offer to install:

curl -fsSL \
  -H "Authorization: Bearer $SETUP_SERVICE_KEY" \
  -o qwickapps-slack-bridge.user.js \
  {{.SetupURL}}/userscript.user.js

# Then drag the saved .user.js onto Tampermonkey's dashboard,
# or open the file:// path in your browser.

The downloaded .user.js is pre-configured with this deployment's BRIDGE_URL and BRIDGE_HMAC_KEY.

First-Time HMAC Key Setup

Generate a random 32-byte key and set it in the environment before deploying:

openssl rand -hex 32

Set the output as BRIDGE_HMAC_KEY in both the token-bridge service and this setup service. They must share the same value.

Set SETUP_SERVICE_KEY to a separate random value used to authenticate access to this page.
